# Vendored Geist webfonts

The two Latin variable WOFF2 files and their corresponding OFL notices are vendored from
`@fontsource-variable/geist@5.3.0` and `@fontsource-variable/geist-mono@5.3.0`. Each file covers
normal weights 100–900; refresh the assets and notices together. `main.css` uses Geist for the
page, while `main.js` exposes both faces to the same-origin SVG card documents.
